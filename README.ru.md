# Multi (`multi`)

[English →](README.md) · [中文 →](README.zh.md)

используй **мульти**-модельную систему для код-ревью, проверки выполнения задачи, планирования или просто вопросов.  
сейчас можно использовать суб-агентов Claude Code + Codex + OpenCode + Gemini + headless режим Claude Code с ключом опенраутер если ты его предоставишь. хорошая база для старта - клод + кодекс. клод делает и проектирует, кодекс проверяет.  
можно =/= нужно, много моделей не значит что результат будет лучше, выбирай просто то, что у тебя есть/что тебе дешевле (или чё хош, мне то что ахахах, вдруг это всё таки лучше будет)

| команда | что делает |
|---|---|
| `/multi:code-review` | ревью кода всеми модельками, а Claude Code (!) сводит всё в один отчёт |
| `/multi:check-if-done` | работа реально доделана или только выглядит доделанной, каждое "«"готово"»" подтверждено реально запущенной командой |
| `/multi:ask` | задаёшь один вопрос всем сразу и смотришь три ответа рядом. никто не судит, никто не проверяет |
| `/multi:adhd` | накидать идей вширь - 5 когнитивных рамок, каждая уходит своей модели, потом всё оценивается и сводится в шортлист |
| `/multi:setup` | объясняет тебе чо и как тут подключить  |

## README по-человечески

как не трудно догадаться, это использование нескольких моделей вместо одной:

1. `/multi:code-review` - ревью кода саб-агентами Claude, запросом к Codex (через headless exec) и headless-запросом к OpenCode + линза [ponytail](https://github.com/DietrichGebert/ponytail) на оверинжиниринг. глянь описание плагина ponytail, штука прикольная
2. `/multi:check-if-done` - та самая "а задача точно готова??? перепроверь!!!!". модель, которая только что написала код - худший судья того, работает ли он, поэтому тут спрашиваем те модели что не писал этот код, и ничего не зовём готовым, пока реально не прогоним команду, которая это докажет. должно чинить случаи "ой извини я поспешил с выводами ЛОООЛ"
3. `/multi:ask` - просто спроси у всех одно и то же и получи три ответа. три ответа, без слияния, без судейства
4. `/multi:adhd` - запускает скилл [adhd](https://github.com/UditAkhourii/adhd) на всех твоих провайдерах, которые есть. типа мега-план со всех сторон
5. `/multi:setup` - онбоардинг скилла, объяснит тебе что куда и зачем


установка
```bash
claude plugin marketplace add szarkans/multi
claude plugin install multi@szkills

или
npx skills add szarkans/multi

или
git clone https://github.com/szarkans/multi ~/.claude/skills/multi
```

потом перезапусти claude code и в целом просто попроси его всё настроить и всё. там кодекс логин, опенкод + модель в нём и т.д., клауд разберёстя сам
