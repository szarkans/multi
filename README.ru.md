# multi

[English →](README.md) · [中文 →](README.zh.md)

`multi` прогоняет одну задачу через несколько ИИ сразу — код-ревью, "а точно done", [adhd](https://github.com/UditAkhourii/adhd)-планирование, или просто вопрос — и показывает где модели сходятся, а где расходятся. решаешь ты, не они.

сейчас поддерживает:
- саб-агентов Claude
- codex
- opencode
- gemini
- headless claude code с любым API-ключом, который ты дашь (например openrouter)

он **умеет** пользоваться всеми этими моделями, но это не значит что так будет **лучше** — все они всё ещё просто LLM. используй что есть/что хочешь (или вообще всё сразу, мне пофиг, yolo)

## Команды

ну короче как и следует из названия - несколько моделей вместо одной:

1. `/multi:code-review` - ревью кода несколькими агентами, потом перепроверка находок + линза [ponytail](https://github.com/DietrichGebert/ponytail) на оверинжиниринг
2. `/multi:check-if-done` - та самая "бро, а точно готово?". модель, которая только что написала код - худший судья того, работает ли он, поэтому тут спрашиваем модели, которые его не писали, и не зовём ничего готовым, пока реально не прогоним команду, которая это докажет. должно чинить кейсы "выглядит готовым, но на самом деле нет, сорян"
3. `/multi:ask` - просто спроси у всех одно и то же и получи три ответа - без слияния, без судейства
4. `/multi:adhd` - призывает все модели со скиллом [adhd](https://github.com/UditAkhourii/adhd). типа мега-крутой режим планирования
5. `/multi:setup` - рассказывает что за плагин и как всё подключить и всё такое

установка
```bash
claude plugin marketplace add szarkans/multi
claude plugin install multi@szkills

или
npx skills add szarkans/multi

или
git clone https://github.com/szarkans/multi ~/.claude/skills/multi
```

потом перезапусти claude code и `/multi:setup`
